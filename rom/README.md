Put the Space Invaders ROM here as `space-invaders.rom` (8192 bytes: invaders.h, .g, .f
and .e concatenated, e.g. the file shipped with cbeust/space-invade.rs), and optionally the
WAV samples in `sounds/` (ufo_lowpitch, shoot, explosion, invaderkilled,
fastinvader1-4). They are not part of this repository.
